# [Linux] Stockage insufisant

> **En résumé :** Sur une de mes VMs ubuntu, j'ai remarqué que mon stockage n'est pas suffisant et qu'il est utilisé à 70%

---

## Informations

- **Catégorie :** Linux
- **Date :** 2026-07-31
- **Système / Version :** Ubuntu 26.04 LTS

---

## Erreur & Symptômes

J'ai donc tapé cette commande pour voir le stockage système qui me reste:

```bash
df -h /
```

et voici le résultat:

```bash
Filesystem                         Size  Used Avail Use% Mounted on
/dev/mapper/ubuntu--vg-ubuntu--lv   12G  7.5G  3.2G  70% /
```

---

## Cause du problème

La cause vient du fonctionnement par défaut de l'installateur d'Ubuntu (appelé Subiquity).

Quand on installes Ubuntu Server et qu'on laisses les options de stockage cochées par défaut, l'installateur utilise LVM (Logical Volume Manager) avec une règle très précise :

1. Il détecte bien l'intégralité de notre disque virtuel de 25 Go.

2. Il crée un groupe de stockage (Volume Group : ubuntu-vg) de 25 Go.

3. Mais il ne crée la partition racine (/) qu'avec environ 50 % de l'espace (soit ~12 Go max).

---

## Solution

[Procédure étape par étape avec les commandes shell ou photos précises à exécuter]

```bash

# Donne tout l'espace en réserve à la racine /
sudo lvextend -l +100%FREE /dev/mapper/ubuntu--vg-ubuntu--lv

# Agrandis le système de fichiers pour utiliser l'espace débloqué
sudo resize2fs /dev/mapper/ubuntu--vg-ubuntu--lv
```

et bam c'est bon

```bash
Filesystem                         Size  Used Avail Use% Mounted on
/dev/mapper/ubuntu--vg-ubuntu--lv   23G  7.5G   15G  35% /
```
