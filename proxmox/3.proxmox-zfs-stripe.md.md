# [Proxmox] Fusion de 2 disques en ZFS Stripe (RAID0) et nettoyage d'affichage GUI

> **En résumé :** L'interface Proxmox bloque la sélection multiple en mode **Single Disk** pour créer un RAID0 ZFS.

---

## Informations

- **Catégorie :** Proxmox
- **Date :** 2026-08-06
- **Système / Version :** Proxmox 8.4.0

---

## Erreur & Symptômes

Impossible de sélectionner deux disques à la fois dans l'assistant Create: ZFS (absence du choix RAID0 explicite et verrouillage du mode Single Disk).

Avertissement contrôleur matériel Dell :

```
Note: ZFS is not compatible with disks backed by a hardware RAID controller.
```

---

## Cause du problème

**Création :** La GUI Proxmox ne propose pas la création d'un pool ZFS Stripe à disques multiples sous **Single Disk**

**Contrôleur :** Les disques sont montés sur un contrôleur Dell PERC 6/i (carte RAID matérielle) au lieu d'un mode HBA / IT Pass-through.

---

## Solution

### 1. Création du pool ZFS Stripe (RAID0) via le Shell

Créer directement le pool avec l'ensemble des disques cibles pour contourner la limitation de la GUI :

```bash
zpool create -f stockage-data /dev/sdb /dev/sdc
```

### 2. Ajout du stockage dans Proxmox

- Aller dans Datacenter > Storage > Add > ZFS.

- ID : stockage-data

- ZFS Pool : stockage-data

- Node : Choisir le noeud concerné

- Définir le contenu (Image disque / Container) et valider par Add.
